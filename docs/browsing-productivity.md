# Browsing & Productivity

Password and login-security tools for everyday use.

---

### KeePassXC
[keepassxc.org](https://keepassxc.org)

| | |
|---|---|
| Encryption | AES, local database |
| Open source | Yes |
| Audited | Yes |
| Self-host | N/A — local file |
| Cost | Free |
| Platforms | Windows, Mac, Linux |

**Best for:** Full control of your password database, no cloud dependency.
**Avoid if:** You want automatic multi-device sync without setting it up yourself.

---

### Bitwarden
[bitwarden.com](https://bitwarden.com)

| | |
|---|---|
| Encryption | End-to-end (zero-knowledge) |
| Open source | Yes |
| Audited | Yes, regular |
| Self-host | Yes |
| Account needed | Email |
| Cost | Freemium |
| Platforms | Android, iOS, Windows, Mac, Linux |

**Best for:** A password manager that syncs effortlessly across every device.
**Avoid if:** You don't want any cloud-hosted copy, even encrypted — use KeePassXC instead.

---

### Aegis Authenticator
[getaegis.app](https://getaegis.app)

| | |
|---|---|
| Encryption | Local, encrypted export |
| Open source | Yes |
| Cost | Free |
| Platforms | Android |

**Best for:** Two-factor codes kept off any company's server.
**Avoid if:** You're on iPhone — Aegis is Android-only.
