# Communications & Messaging

Tools for private messaging, calls, and email.

---

### Signal
[signal.org](https://signal.org)

| | |
|---|---|
| Encryption | End-to-end |
| Open source | Yes |
| Audited | Yes, protocol widely audited |
| Logging | Minimal metadata, no message content |
| Jurisdiction | US nonprofit |
| Cost | Free |
| Self-host | No |
| Account needed | Phone number |
| Platforms | Android, iOS, Windows, Mac, Linux |

**Best for:** Default choice for most people; easiest to get contacts onto.
**Avoid if:** A phone number would identify or endanger you.

---

### SimpleX Chat
[simplex.chat](https://simplex.chat)

| | |
|---|---|
| Encryption | End-to-end |
| Open source | Yes |
| Audited | Partial, ongoing |
| Logging | No persistent user ID |
| Jurisdiction | UK |
| Cost | Free |
| Self-host | Yes (relays) |
| Account needed | None |
| Platforms | Android, iOS, Windows, Mac, Linux |

**Best for:** Talking to someone with zero identifying signup info.
**Avoid if:** You need a large contact list already on a mainstream platform.

### Briar
[briarproject.org](https://briarproject.org)

| | |
|---|---|
| Encryption | End-to-end |
| Open source | Yes |
| Audited | Partial |
| Logging | None |
| Jurisdiction | UK nonprofit |
| Cost | Free |
| Self-host | N/A — peer-to-peer |
| Account needed | None |
| Platforms | Android, Windows, Mac, Linux |

**Best for:** No or unreliable internet, or you expect connectivity to be cut.
**Avoid if:** Contacts aren't tech-comfortable — pairing is more manual than Signal.

---

### Thunderbird + OpenPGP
[thunderbird.net](https://www.thunderbird.net)

| | |
|---|---|
| Encryption | End-to-end (message body) |
| Open source | Yes |
| Audited | Yes (OpenPGP widely reviewed) |
| Logging | N/A — your own email account |
| Jurisdiction | Depends on your email provider |
| Cost | Free |
| Self-host | Yes (your mail server) |
| Account needed | Existing email |
| Platforms | Windows, Mac, Linux |

**Best for:** Encrypted email with people who already use PGP.
**Avoid if:** Contacts won't set up PGP keys — subject lines/metadata stay unencrypted regardless.
