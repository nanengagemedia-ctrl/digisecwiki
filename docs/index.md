# Digital Security Tool Directory

A maintained, plain-language directory of free and open-source (FOSS) digital security tools — organized around what you're actually trying to do, not around product names.

Most people don't know what kind of protection they need; they just know something feels wrong, or they have a task in mind and no idea which tool fits it. This directory works backward from that.

## Start here

- **[Guided Tool Finder](tools-finder.md)** — answer a few plain questions, get a prioritized recommendation with next steps, embedded directly on this site.
- **[Comparison Table](tools-compare.md)** — compare every cataloged tool on encryption, audits, jurisdiction, cost, and self-hosting.
- **[If You Don't Feel Safe](if-you-dont-feel-safe.md)** — situation-first guidance, not just a tool list.

## A note on gaps

Where no vetted FOSS tool exists for a real need (consumer anti-malware is the clearest example right now), that's stated explicitly rather than papered over with an unrelated recommendation. This directory is maintained on an ongoing basis — gaps get filled as the FOSS landscape changes, not treated as permanent.
